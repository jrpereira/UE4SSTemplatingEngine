# Template directory

TE registers this directory through the host's file-enumeration adapter. `default.lua` declares TE's default Templates-menu behavior. Quickslots++ is defined in QuickslotsForever's `templates/quickslots.lua` and must be registered by the consumer integration.

Adaptive Mod Menu's inert settings-page fix metadata is defined in `AdaptiveModMenu/template/fixes.lua` and registered explicitly by the host profile under `menu.fixes`.
